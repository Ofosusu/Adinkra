# Adinkra

**Discover Your Roots. Experience Ghana.**

Adinkra is a cultural discovery and travel platform project for
African Americans interested in exploring Ghana, learning about
Ghanaian history, and discovering meaningful cultural experiences.

## Project Goals

- Help visitors discover destinations across Ghana.
- Explain Ghanaian history and cultural traditions.
- Explore connections between Ghana and the African diaspora.
- Help travelers research tours and plan itineraries.
- Showcase local guides, cultural experiences, and communities responsibly.

## Current Technologies

- HTML
- CSS
- JavaScript
- JSON for starter data

## Run Locally

Open `index.html` in a web browser, or run a local development server
from the project folder.

If Python 3 is installed, you can use:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000 in your browser.

Press Control+C in Terminal to stop the local server.

## Main Project Structure

- `index.html` — Homepage
- `pages/` — Website pages
- `css/` — Stylesheets
- `js/` — Front-end JavaScript
- `data/` — Starter JSON data
- `assets/` — Images, icons, logos, and fonts
- `docs/` — Project and architecture documentation
- `tests/` — Testing notes and checklists
- `server/` — Planned future backend structure

## Development Status

This is an early project skeleton. Search, accounts, bookings, payments,
AI recommendations, and backend APIs are not implemented yet.

Before publishing travel or historical information, add reliable sources.
Verify tour operators and prices before listing them as available services.
Do not present general cultural connections as proof of a person's ancestry.
