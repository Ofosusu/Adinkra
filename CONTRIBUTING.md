# Contributing to Adinkra

Contributions should support the project's goal of helping visitors
discover Ghana, learn about its heritage, and plan meaningful journeys.

1. Check existing issues before starting major work.
2. Use a separate branch for a feature or fix.
3. Keep changes focused and describe them clearly.
4. Test relevant pages before submitting a pull request.
5. Cite sources for historical or cultural content.
6. Respect image licenses and personal privacy.
