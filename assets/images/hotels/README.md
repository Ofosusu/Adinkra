# Hotel Pictures

Each hotel card looks for a photo named `<slug>.jpg` in this folder. If the
photo is missing, it shows the matching `<slug>.svg` placeholder instead.

To add a real picture:
1. Get a photo you have permission to use (your own photo, written permission
   from the property, or a license that allows reuse).
2. Save it here as `<slug>.jpg` (for example `labadi-beach-hotel.jpg`).
3. Record the photographer, source and license in `assets/ASSET_CREDITS.md`.
