# Manual Testing Checklist

- [ ] Homepage loads successfully.
- [ ] Navigation links open the correct pages.
- [ ] CSS and JavaScript load on every page.
- [ ] Footer year updates automatically.
- [ ] Website can be read on a phone-sized screen.
- [ ] Keyboard focus is visible.
- [ ] Images have appropriate alternative text when added.
- [ ] Content sources and image credits are recorded.
- [ ] No passwords or API secrets are committed.
