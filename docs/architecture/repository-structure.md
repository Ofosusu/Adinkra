# Repository Structure

## Front End

- `index.html` is the homepage.
- `pages/` contains the other website pages.
- `css/` separates base styles, layouts, components, and page styles.
- `js/` is organized for shared components, page logic, services, and utilities.
- `data/` stores structured starter content in JSON.
- `assets/` stores images, icons, logos, and fonts.

## Documentation and Quality

- `docs/` contains product, architecture, content, and development notes.
- `tests/` contains testing checklists and test plans.
- `.github/` contains templates and future workflow automation.

## Planned Backend

`server/` reserves a place for future API routes, modules, middleware,
database configuration, migrations, and automated tests.

The backend is only a planned structure at this stage. No API, database,
authentication, booking engine, or server application has been implemented.
